Temuan source tambahan: setiap Numeric memicu save baru ke Channel.UNLIMITED; Repository.saveDay membaca semua laporan dan upsert semua hasil rekonsiliasi walau mayoritas tidak berubah. Ini bukti penulisan berlebihan, bukan klaim benchmark lag dari video. Perbaikan: gabungkan snapshot terbaru per ID, jurnal pemulihan draf, barrier sebelum operasi lanjutan, dan tulis hanya payload yang berubah. Status error ekspor dipisahkan dari kegagalan menyimpan data.

Business logic StockLedger/Calculation dan grid resmi dievaluasi sebagai batas regresi. Rumus, pemisahan sales/tester, penandaan laporan final terdampak, margin A4 dan formula helper Excel dipertahankan. SQL Room version 1 tidak diubah.
